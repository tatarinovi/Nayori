# Журнал буфера обмена

Журнал открывается возле курсора. Слева — список записей без миниатюр, справа — превью выбранного объекта и подпись. Изображение помещается целиком; «Превью» расширяет область просмотра внутри окна. Текст можно выделять мышью.

Открыть или закрыть журнал:

```sh
qs ipc -p /absolute/path/to/nayori call clipboard toggle
```

Бинд в блоке `binds` конфигурации niri, например:

```kdl
Mod+V repeat=false {
    spawn "qs" "ipc" "-p" "/absolute/path/to/nayori" "call" "clipboard" "toggle";
}
```

`spawn` принимает программу и аргументы отдельно. `spawn-sh` нужен для одной строки с синтаксисом shell — например, с конвейером или `$HOME`. Команда управляет уже запущенной оболочкой; второй экземпляр Nayori запускать не нужно. Сам журнал конфигурацию niri не меняет.

## Управление

- Поле поиска фильтрует названия и сохраненный фрагмент текста. Фильтры: «Всё», «Медиа», «Текст», «Закреплено».
- ↑ и ↓ меняют выбранную запись. Enter в поиске и двойной щелчок копируют исходные данные, закрывают журнал и пробуют вставить их в приложение, которому вернулся фокус. Кнопка «Копировать» возвращает данные в системный буфер и закрывает журнал без вставки.
- Иконка кнопки закрепления и отметка в списке рисуются в Canvas, независимо от шрифтов. Закрепленные записи защищены от вытеснения лимитом истории.
- Кнопка с корзиной удаляет выбранную запись из истории.
- «Очистить» удаляет всю историю, включая закрепленные записи, и очищает текущий системный буфер.
- Esc сначала сворачивает расширенное превью, затем закрывает окно. Щелчок вне окна и повторный вызов бинда тоже закрывают журнал.

Заголовок содержит счетчик: «Буфер обмена · 12». Под превью показываются формат, размер данных и разрешение изображения или видео, если оно доступно.

## Источники и хранение

`services/clipboard/clipboard_store.py` запускается одним `ClipboardService` на оболочку. Два наблюдателя `wl-paste --watch` получают изображения и текст. Python сохраняет оригинальные байты; QML получает только метаданные и пути превью. Копирование использует `wl-copy` с явным MIME-типом, без подстановки содержимого в shell.

Поддерживаются растровые данные PNG, JPEG, GIF, WebP, BMP и TIFF, UTF-8-текст и локальные файлы в формате `file://…`. Для одного файла изображения используется его превью, для видео — первый кадр, если доступен FFmpeg. Путь и MIME `text/uri-list` сохраняются для повторного копирования файла; исходные файлы не изменяются. Несколько файлов остаются одной записью списка URI. Перемещение или удаление исходного файла может сделать его превью недоступным.

История сохраняется в `$XDG_STATE_HOME/nayori/clipboard`, по умолчанию — `~/.local/state/nayori/clipboard`. SQLite хранит исходные данные и метаданные, рядом лежат приватные файлы превью. Каталог имеет права 0700, файлы — 0600. Маркер чувствительного содержимого `CLIPBOARD_STATE=sensitive`, который передает wl-paste, исключает запись из истории. Это зависит от корректной маркировки источником.

Лимиты: 100 записей, 64 МиБ исходных данных, 16 МиБ на изображение, 1 МиБ на текст. Старые незакрепленные записи вытесняются первыми; повторное копирование поднимает существующую запись, сохраняя закрепление. Лимиты не включают размер внешних файлов, которые хранятся ссылками. Для текстового превью и поиска передаются первые 16 000 символов, повторное копирование возвращает весь сохраненный текст.

Зависимости: Python 3 и `wl-clipboard` (`wl-paste`, `wl-copy`). `ffprobe` получает размеры видео и дополнительных форматов изображений; `ffmpeg` создает кадр видео. Без FFmpeg остальные функции работают, недоступные метаданные не подставляются. Размеры PNG и GIF из скопированных байтов определяются без дополнительных библиотек.

Автовставка использует фиксированное сочетание Ctrl+V через протокол Wayland `zwp_virtual_keyboard_v1` (`services/clipboard/paste_shortcut.py`). Вспомогательный процесс отправляет только это сочетание; он не читает ввод и не требует root, `wtype` или `ydotool`. Запрос отправляется после закрытия поверхности и возврата фокуса, с паузой 40 мс. Повторное открытие журнала или переход в другое меню Nayori отменяет отложенную вставку. Если композитор запрещает виртуальную клавиатуру или приложение не поддерживает Ctrl+V для этих данных, содержимое остается в буфере для ручной вставки. Подтверждение протокола означает доставку клавиш, а не подтверждение вставки приложением.

## Окно и движение

При открытии прозрачные поверхности на выходах получают начальный Wayland pointer-enter. Его координаты определяют монитор и точку открытия без чтения устройств ввода; затем точка фиксируется. Окно отступает от курсора на 12 логических пикселей, переворачивается к другой стороне и ограничивается краями экрана. Если pointer-enter не пришел за 250 мс, используется центр активного монитора. При закрытии поверхности уничтожаются.

Анимация меняет прозрачность и высоту области показа от стороны курсора за `tokens.motion.fast` — 140 мс, с кривой `[0.23, 1, 0.32, 1]`. Окно и его текст сохраняют размер; меняется отсечение. Область размытия повторяет видимую область на каждом кадре, сжимаясь до нуля. После этого отправляется полностью прозрачный кадр с пустым блюром; только после `frameSwapped` поверхность уничтожается. Это исключает оставшееся размытие в анимации закрытия композитора. Повторный вызов во время закрытия разворачивает переход на том же окне. Выключение анимаций в настройках убирает переход. Слой не меняет размер во время анимации; ввод получает окно, которое открыто на выбранном мониторе.

## Проверки

```sh
python3 tests/clipboard-store.py
node tests/clipboard-logic.cjs
XDG_RUNTIME_DIR=/tmp/nayori-clipboard-smoke-runtime QT_QPA_PLATFORM=offscreen QT_QPA_PLATFORMTHEME=basic QT_QUICK_BACKEND=software qs -p tests/smoke/ClipboardSmoke.qml
python3 tests/clipboard-window.py
python3 tests/root-config.py
```

Перед offscreen-проверкой создайте каталог `XDG_RUNTIME_DIR` с правами 0700. Первые проверки используют подставные данные и команды копирования, не обращаясь к текущему буферу. `clipboard-window.py` требует Wayland и создает вложенный niri в отдельном runtime: проверяет настоящий слой, фокус поиска без наведения, синхронизацию блюра с закрытием, финальный прозрачный кадр, прерывание анимации и режим без анимаций. Затем тестовый текст копируется только в буфер вложенного композитора, а Ctrl+V действительно вставляет его в тестовое поле после возврата фокуса. Компиляция корневого файла проверяется без создания его рабочих поверхностей.
