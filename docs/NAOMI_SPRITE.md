# Naomi v3 — минимальный idle-прототип

Третий облик: «Настройки → Naomi → Внешний вид», пункт «Облик Naomi», вариант «Naomi v3». Ключ `companionStyle: "layered"` хранится вместе с остальными настройками. Текущая иллюстрация (`current`) и Pixel art (`pixel-art`) остаются. По умолчанию выбран `current`.

## Компонент

`surfaces/companion/NaomiSprite.qml` использует только Qt Quick. Его можно поставить как обычный `Item`. Собственный размер — холст 305×1024. В слоте компаньона ему задают 280×534, и картинка вписывается внутрь.

```qml
NaomiSprite {
    width: 280
    height: 534
    running: true
    animationsEnabled: true
}
```

Десять отдельных `Image` читают PNG из `assets/naomi/v3`. Каждый слой сохраняет общий холст 305×1024 и общее начало координат. Порядок из `assets/naomi/v3/manifest.json`: legs → body → hair_back → clothing → head → arm_right → arm_left → hair_front → eyes → mouth. Сцена масштабируется с сохранением пропорций. Множитель — `min(width / 305, height / 1024) × 0,97`, запас 3% по ограничивающей стороне.

Дыхание верхней части тела: подъём на 0–2,5 экранных пикселя и масштаб 1–1,01, цикл 6 с. Голова покачивается на ±1,5° за 7 с. Передние волосы добавляют до 0,45°, задние — до 0,35° в другую сторону, цикл 8,2 с. Ноги неподвижны. Руки, одежда и тело идут только вместе с дыханием. Моргание — прозрачность слоя eyes каждые 5 с: закрытие 80 мс, пауза 90 мс, открытие 110 мс. Рот остаётся нейтральным и поворачивается вместе с головой. Цвета и PNG не меняются.

`running` включает и выключает цикл. `active` останавливает скрытый предпросмотр. `animationsEnabled` учитывает общий переключатель анимаций. Пока цикл не идёт, поза нейтральная и глаза открыты. `ready` и `failed` показывают загрузку слоёв. `assetDirectory` подставляет другой каталог с теми же именами и тем же холстом.

`headRect` и `bubbleAnchor` этого компонента — зона головы для маски окна и хвоста облака. Жест поглаживания описан в `docs/NAOMI.md`.

## Демо

Из корня репозитория:

```sh
qs -p naomi-sprite-demo.qml
```

Окно прозрачное, 360×700. Спрайт внутри — 280×610. Под ним кнопка «Остановить idle» / «Запустить idle».

## Проверка

```sh
python3 tests/naomi-sprite.py
python3 tests/settings.py
```

Стенд проверяет десять файлов, общий холст и порядок слоёв, прозрачность кадра, диапазон дыхания, моргание, остановку и запуск, отключение анимаций и переключение трёх обликов без потери контроллера и реплики.
