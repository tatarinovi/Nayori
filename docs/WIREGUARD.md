# WireGuard

В меню сети в трее и на странице «Система → Сеть» есть блок WireGuard. Он показывает сохранённые профили NetworkManager. Нажатие на профиль подключает или отключает его. Во время операции кнопки недоступны; состояние меняется после ответа NetworkManager. Ошибка остаётся видимой до следующей операции или нажатия «Обновить список».

Кнопка «Импортировать .conf» открывает выбор локального файла WireGuard. Конфигурация передаётся в `nmcli connection import type wireguard file …`; профиль и ключи хранит NetworkManager. Nayori не копирует ключи в свои настройки и не выводит содержимое конфигурации в журнал. При импорте применяются обычные правила NetworkManager, включая автоподключение, маршруты и DNS профиля. Импорт не запускает отдельную команду подключения.

Для работы нужны NetworkManager с `nmcli` и Python 3 — они уже входят в зависимости установщика. Системные разрешения NetworkManager действуют и здесь. При отказе в доступе проверьте политику NetworkManager и системный агент polkit.

Профили, поднятые только через `wg-quick` или отдельную службу systemd, не входят в этот список: сначала импортируйте их в NetworkManager. «Подключено» означает активное соединение NetworkManager; это не проверка handshake или доступности удалённого сервера.

## Устройство

- `surfaces/settings/WireGuardControls.qml` — общий интерфейс для трея и страницы сети, выбор файла, состояния, ошибки и прокрутка к кнопке при переходе с клавиатуры.
- `services/system/WireGuardControl.qml` — асинхронные запросы, защита от повторного нажатия и устаревшего ответа списка. Ошибки операции отделены от ошибок обновления списка.
- `scripts/wireguard-control.py` — список профилей и операции `up`, `down`, `import`; JSON по stdout. Аргументы передаются без shell, профиль перед каждой операцией проверяется по UUID и типу `wireguard`. Для списка запрашиваются только `NAME,UUID,TYPE,ACTIVE,STATE,DEVICE`.

Пока меню или страница сети открыты, `nmcli monitor` сообщает об изменениях устройств, соединений и профилей. События объединяются с задержкой 150 мс. При закрытии монитор завершается; начатая пользователем операция дорабатывает. Таймера периодического опроса нет. Следующее открытие заново читает список.

## Сравнение с AngelOS и Noctalia

Проверены исходники:

- AngelOS, коммит `6713f8945e41998c24000de2e9050f17749ce74a`: [страница сети](https://github.com/MixaDoDs/AngelOS-Dotfiles/blob/6713f8945e41998c24000de2e9050f17749ce74a/.config/quickshell/angelos/modules/settings/catalog/Network.qml). Отдельного блока WireGuard/VPN в этой странице нет.
- Noctalia, коммит `e4390429240b7c761c948289a87463ff9d5b18c4`: [сервис NetworkManager](https://github.com/noctalia-dev/noctalia-shell/blob/e4390429240b7c761c948289a87463ff9d5b18c4/src/dbus/network/network_manager_service.cpp) и [вкладка сети](https://github.com/noctalia-dev/noctalia-shell/blob/e4390429240b7c761c948289a87463ff9d5b18c4/src/shell/control_center/tabs/network_tab.cpp). Сервис включает тип `wireguard` в список VPN; интерфейс предлагает подключение и отключение сохранённых профилей. Виртуальный туннель отделён от состояния физического подключения.

Nayori использует тот же принцип отдельного списка профилей, со своей реализацией на QML и `nmcli`. Установленный `Quickshell.Networking` предоставляет Wi-Fi и Ethernet, поэтому WireGuard обслуживается отдельно. Исходники других оболочек не копировались.

## Проверки

```sh
python3 tests/wireguard.py --unit
python3 tests/wireguard.py
NAYORI_WG_PREVIEW=/tmp/nayori-wireguard.png python3 tests/wireguard.py
```

Проверки подменяют `nmcli` искусственным процессом через `PATH` и не меняют реальную сеть. Покрыты фильтрация профилей, экранирование имён, одинаковые имена, проверка UUID и типа перед операцией, импорт пути с пробелами и символами shell, ошибки доступа и тайм-ауты. QML-стенд проверяет подключение, отключение, защиту от двойного нажатия, завершение операции после закрытия, сохранение ошибки, импорт, внешнее изменение состояния, отсутствие NetworkManager, пустой список и остановку монитора. Он также открывает настоящее меню сети `StatusIsland` с искусственными профилями. Превью сохраняются в указанный файл и рядом с суффиксом `.tray.png`.
