# Полка Dynamic Island

Третья вкладка острова хранит файлы, папки, изображения, видео, ссылки и текст между запусками. Элементы можно перетаскивать в другие приложения. Обычный элемент убирается только после принятого переноса; отменённый перенос ничего не удаляет. Закреплённые элементы и созданные вручную заметки остаются.

## Исследование AngelOS

Исследован коммит [`6713f8945e41998c24000de2e9050f17749ce74a`](https://github.com/MixaDoDs/AngelOS-Dotfiles/tree/6713f8945e41998c24000de2e9050f17749ce74a). Основные источники:

- [`services/Shelf.qml`](https://github.com/MixaDoDs/AngelOS-Dotfiles/blob/6713f8945e41998c24000de2e9050f17749ce74a/.config/quickshell/angelos/services/Shelf.qml): модель, дедупликация, закрепление, заметки, сохранение JSON, очередь файловых операций.
- [`modules/halo/HaloWindow.qml`](https://github.com/MixaDoDs/AngelOS-Dotfiles/blob/6713f8945e41998c24000de2e9050f17749ce74a/.config/quickshell/angelos/modules/halo/HaloWindow.qml): интерфейс ShelfCard/ShelfTile, редактор заметки, избранные папки, входящий и исходящий drag-and-drop.
- [`scripts/shelf-fetch.py`](https://github.com/MixaDoDs/AngelOS-Dotfiles/blob/6713f8945e41998c24000de2e9050f17749ce74a/.config/quickshell/angelos/scripts/shelf-fetch.py): загрузка изображений HTTP/data URI, определение формата по байтам, недоступные browser blob URL.
- [`tests/shelf/ShelfDriver.qml`](https://github.com/MixaDoDs/AngelOS-Dotfiles/blob/6713f8945e41998c24000de2e9050f17749ce74a/.config/quickshell/angelos/tests/shelf/ShelfDriver.qml): проверка файлов, ссылок, изображений, закрепления, перемещения в папку и состояния.

В AngelOS интерфейс Dynamic Island называется **Halo**; `services/Island.qml` относится к отдельному окну браузера. Shelf — отдельный singleton, не история буфера. Локальные файлы хранятся ссылками на исходные пути; изображения из браузера скачиваются. Повторный элемент поднимается вверх без потери закрепления. Звёздочка сохраняет элемент после выдачи, а закреплённая папка принимает копии файлов с новым именем при конфликте. Заметки редактируются отдельно и остаются после переноса. Halo также предлагает множественный выбор, QuickLook и QuickShare, связанные с собственными сервисами AngelOS.

Особенность Qt/Wayland и Chromium под Niri: браузер может передавать изображение как `application/octet-stream; name=…`, а Qt переименовывает `text/x-moz-url`. AngelOS предварительно читает предложенные MIME-данные при входе в DropArea, пока источник ещё отвечает. В Nayori этот приём реализован в `ShelfDrop.prefetch`, без вывода содержимого буфера или перетаскивания в журнал.

## Реализация Nayori

- `shell.qml` создаёт один `ShelfService` для всех мониторов. Вкладки получают его через `ScreenPanels` и `MorphingIsland`.
- `services/shelf/ShelfService.qml` — мост JSON Lines к одному последовательному Python-процессу. Он сообщает готовность, занятость и ошибки и восстанавливается после остановки worker.
- `services/shelf/shelf_store.py` хранит SQLite и собственные медиа в `$XDG_STATE_HOME/nayori/shelf` (по умолчанию `~/.local/state/nayori/shelf`). Транзакции защищают сохранение модели. Каталог имеет права 0700, база и медиа — 0600.
- `surfaces/island/ShelfPage.qml` использует `IslandCard`, `IslandAction`, `IslandLabel` и токены Nayori. У карточки есть выбор, двойное нажатие открывает файл/ссылку или редактор текста. Панель действий позволяет копировать, открывать, закреплять и удалять выбранный элемент. Поле заметки и кнопки имеют высоту 36 px.
- `surfaces/island/ShelfDrop.js` разбирает MIME, HTML изображения и исходящие URI. Native `Drag.Automatic` передаёт данные приложениям через Qt/Wayland. Файловые URI кодируются через `Path.as_uri`, включая пробелы, `#`, `?` и кириллицу.
- `IslandDashboard.currentPage` теперь поддерживает три страницы и прежнюю анимацию. Колесо над заголовками и стрелки на вкладках переключают страницы; колесо над содержимым прокручивает список. Просмотр полки не помечает уведомления просмотренными. При повторном раскрытии сохранено прежнее правило выбора главной/уведомлений.
- Входящий drag над свёрнутым островом открывает полку. Перетаскивание и ввод заметки удерживают её от автоматического закрытия. Фокус остаётся `WlrKeyboardFocus.OnDemand`.

## Буфер обмена и совместимость

Кнопка **«Вставить»** читает текущее выделение Wayland через существующий `ClipboardService`, а не выбирает первый элемент истории. Расширения `readCurrent` и `copyContent` выполняются тем же worker; второго наблюдателя или clipboard-сервиса нет.

Поддержаны текст, изображения PNG/JPEG/GIF/WebP/BMP/TIFF, байты видео MP4/WebM/Ogg и URI файлов из файлового менеджера. Для входящих байтов фото/видео создаётся собственный файл полки: очистка истории буфера его не удаляет. Обычные локальные файлы, включая фото и видео, остаются ссылками на оригиналы. После перемещения или удаления оригинала карточка помечается недоступной; её можно удалить или сохранить закреплённой.

Встроенные QuickLook/QuickShare AngelOS не переносились: просмотр и открытие выполняет `xdg-open`, «В папке» открывает родительский каталог. Множественного выбора нет. Изображения доступны для предварительного просмотра на карточке, видео открывается системным проигрывателем. Для ссылок без изображения и при сбое загрузки сохраняется исходный адрес. Browser `blob:` без переданных байтов недоступен вне процесса браузера: показывается ошибка.

Ограничения: до 200 элементов, текст до 64 000 символов, входящие байты изображения/видео до 16 МиБ, собственный кэш медиа до 128 МиБ. Размер файлов, добавленных по URI, этим ограничением не связан. Неиспользуемые собственные медиа удаляются при следующем запуске: после принятого drag получателю нужно время, чтобы прочитать файл. Оригиналы при удалении карточек не удаляются. Копирование в закреплённую папку не перезаписывает одноимённый файл и запрещает копирование папки внутрь самой себя.

Зависимости: существующие Python 3 и `wl-clipboard`, `xdg-open` для открытия. Изменения конфигурации Niri, X11-инструменты и эмуляция клавиатуры для полки не требуются.

## Проверки

```sh
bash scripts/check-shelf.sh
python3 tests/clipboard-store.py
bash scripts/check-island.sh
```

`check-shelf.sh` включён в CI smoke, `shelf-store.py` и `shelf-drop.cjs` — в unit. Проверки используют временные каталоги, offscreen Qt и подставные clipboard-команды. Они проверяют сохранение и перезапуск worker, типы данных, дубликаты, ошибки, отсутствующие файлы, имена с особыми символами, закрепление, заметки, конфликты имён папок, MIME браузера, отмену/успех исходящего переноса, кнопку вставки, одинаковую высоту поля/кнопок и синхронизацию трёх страниц. Регрессионные тесты сохраняют проверку уведомлений и колеса. Реальные межприложенные переносы Chromium ↔ Niri требуют проверки в живом Wayland-сеансе.
