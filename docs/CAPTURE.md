# Скриншоты и запись экрана

Захват встроен в Nayori: отдельная служба владеет снимком, редактором и процессом записи. Выбор области и разметка — QML; фоновые утилиты не открывают собственных окон.

## Зависимости

- `grim`, `python-pillow`, `wl-clipboard` — снимок, обработка PNG и копирование.
- `gpu-screen-recorder` версии 6 или новее — запись области, микрофон, системный звук и пауза.
- `ffmpeg` с `ffprobe` — проверка завершённой записи.
- Шрифт DejaVu Sans — текст на экспортированном изображении.

На CachyOS/Arch пакеты устанавливаются пользователем:

```sh
sudo pacman -S grim python-pillow wl-clipboard gpu-screen-recorder ffmpeg ttf-dejavu
```

## Горячие клавиши niri

Добавьте в существующий блок `binds`, заменив путь к репозиторию, если он отличается:

```kdl
Mod+Shift+S { spawn "qs" "ipc" "-p" "/home/katamy/Projects/nayori" "call" "capture" "screenshot"; }
Mod+Shift+R { spawn "qs" "ipc" "-p" "/home/katamy/Projects/nayori" "call" "capture" "record"; }
Mod+Shift+P { spawn "qs" "ipc" "-p" "/home/katamy/Projects/nayori" "call" "capture" "pause"; }
Mod+Shift+Escape { spawn "qs" "ipc" "-p" "/home/katamy/Projects/nayori" "call" "capture" "stop"; }
```

`record` открывает выбор области, а при активной записи завершает её. `pause` переключает паузу. `stop` только завершает уже начатую запись. `cancel` отменяет выбор или возвращает отсчёт к подготовке.

Захват начинается на мониторе, который niri считает активным. Область ограничена одним монитором. На этапе выделения панель управления не показывается. После отпускания мыши скриншот сразу переходит в редактор, а скринкаст — к настройкам записи. Сама запись начинается только по кнопке «Начать запись».

## Скриншот

При вызове Nayori получает снимок монитора, сохраняя панели, открытые меню и настройки видимыми. Временный кадр записывается без PNG-сжатия, чтобы быстрее открыть выбор области. Слой выбора покрывает весь монитор, включая верхний остров: его область тоже можно выделять и размечать. После выбора области изображение остаётся неподвижным. Инструменты и действия находятся в дополнительном блоке под островом.

| Клавиша | Действие |
| --- | --- |
| A / Ф | Стрелка |
| R / К | Квадрат / рамка |
| T / Е | Текст |
| B / И | Сильный блюр |
| Enter | Сохранить PNG и скопировать изображение |
| Ctrl+Z | Отменить |
| Ctrl+Y | Повторить |
| Ctrl+C | Сохранить PNG и скопировать изображение |
| Ctrl+S | Сохранить PNG |
| Esc | Отменить захват |

Текст добавляется щелчком внутри области. Enter подтверждает подпись и сохраняет и копирует весь снимок. Чтобы продолжить разметку, щёлкните вне поля подписи или выберите инструмент. Пока вводится подпись, буквы не переключают инструмент.

Блюр сводится с пикселями итогового PNG. Исходный снимок хранится только во временном закрытом каталоге и удаляется после сохранения или отмены. Отдельного окна результата нет: обычное уведомление попадает в существующую модель острова. Если копирование не удалось, уведомление сообщает об этом и показывает путь к сохранённому файлу.

## Скринкаст

Выделите область до начала записи. В блоке подготовки можно изменить микрофон, системный звук, курсор, FPS и отсчёт для текущей записи. Формат и качество берутся из настроек. Кнопка «Начать запись» и Enter запускают отсчёт. После отсчёта слой выбора полностью закрывается, а запись начинает GPU Screen Recorder.

Капсула с индикатором, таймером, паузой/продолжением и завершением находится левее часов. У кнопок нет всплывающих подсказок; доступные названия сохранены для экранного диктора. Остров во время записи раскрывается обычным наведением. На паузе время не увеличивается. После остановки файл сохраняется и копируется в буфер с MIME `text/uri-list`, поэтому его можно вставить как файл в поддерживающее приложение. Результат сообщается уведомлением, без окна предпросмотра.

Рамка выделения и рамка текущей записи используют системный акцент. Во время записи рамка пропускает клики и располагается снаружи выбранной области, где позволяют границы монитора; у самого края экрана линия сдвигается внутрь и может попасть в видео. На паузе рамка остаётся видимой с меньшей яркостью. Стандартный цвет в настройках задаёт цвет разметки скриншота.

Системные поверхности, попавшие внутрь выбранной области, видны в видео. Редактор и панель подготовки закрываются до старта; если область не включает верхнюю строку острова, управление остаётся снаружи кадра. При записи всего монитора видимый остров также входит в видео. Остановить запись при скрытом острове можно через IPC или горячую клавишу.

## Настройки

**Настройки → Приложения → Запись экрана** или:

```sh
/home/katamy/Projects/nayori/scripts/nayori-settings --page capture
```

Параметры сохраняются общим `SettingsService` в `settings.json`:

| Ключ | По умолчанию |
| --- | --- |
| `captureShotDir` | `~/Pictures/Screenshots` |
| `captureVideoDir` | `~/Videos/Screencasts` |
| `captureColor` | `#CAA7AA` |
| `captureFps` | `30` |
| `captureFormat` | `mp4` |
| `captureQuality` | `high` |
| `captureCountdown` | `3` |
| `captureMic` | `false` |
| `captureSystemAudio` | `true` |
| `captureCursor` | `true` |

Формат: MP4/H.264/AAC или WebM/VP9/Opus. Качество: `high` («Стандартное») или `very_high` («Высокое»). Папки создаются при сохранении. Ошибка пути или рекордера не выдаётся за успешное сохранение; если после сбоя остался видеофайл, уведомление показывает его путь.
