# Календарь CalDAV

Настройки → Приложения → Календарь: HTTPS-адрес коллекции, calendar home или principal, логин и пароль приложения. Первая версия поддерживает чтение всех найденных календарей; создание и изменение событий не реализованы. Сервер должен поддерживать HTTP Basic с паролем приложения. OAuth не реализован.

Зависимости: `python-icalendar`, `python-recurring-ical-events`, `secret-tool` (libsecret) и работающий Secret Service. При отсутствии зависимостей настройки показывают ошибку. Пароль передаётся процессу по stdin и сохраняется через Secret Service после успешного чтения. В settings.json хранятся только URL и логин. Отключение очищает их, сохранённый пароль остаётся в системном хранилище.

Один CalendarService на оболочку, обновление каждые 15 минут. Окно данных: предыдущий 31 день и следующие 366 дней. Повторения и исключения обрабатывает recurring-ical-events. События на весь день используют исключительную дату окончания. Календарь занимает всю высоту прежней колонки острова. Под датой показано по одной точке на событие, сегодня выделено лавандой. Подписи с текущей датой под сеткой месяца нет. Нажатие на дату сдвигает месяц влево и открывает расписание справа внутри той же области. Кнопка со стрелкой влево или Escape возвращает календарь; следующий Escape закрывает остров. Музыка, погода и размеры острова сохраняются. При отключённых анимациях переход мгновенный. При сетевой ошибке последнее состояние остаётся в памяти, после перезапуска требуется сеть. Дискового кэша нет.

TLS проверяется штатным Python trust store. Переходы HTTP и адреса другого origin отклоняются; при перенаправлении нужно указать конечный HTTPS-адрес. Таймаут запроса 15 секунд, максимум 8 MiB XML и 5000 событий. Живой сервер и Wayland ввод требуют ручной проверки.

Страница дня компактная: стрелка возврата и дата в одной строке, уменьшенные интервалы между событиями. Кнопки «Сегодня» нет. Название события открывает HTTP(S)-ссылку из DESCRIPTION в браузере; при нескольких ссылках приоритет у Telemost и «Переговорки», иначе используется первая. Поддерживаются текстовые и HTML-описания. Без ссылки название остаётся обычным текстом. После изменения требуется обновление календаря.

События дня представлены компактными карточками с временем и названием. Слева проходит связанный вертикальный таймлайн с точкой для каждой карточки. Высота карточек зависит от длины названия; список прокручивается.

Карточка события со ссылкой целиком кликабельна (включая время и отступы), доступна с клавиатуры. Hover слегка усиливает фон и обводку, без изменения цвета названия и подчёркивания. Карточки без ссылки не показывают интерактивный hover.

После окончания события карточка и её отметка на таймлайне отображаются с непрозрачностью 45%. Ссылка недоступна для мыши и клавиатуры, подсветка при наведении отключена. Текущее событие остаётся активным до окончания; событие на весь день — до полуночи исключительной даты окончания. Состояние обновляется вместе с часами острова каждые 30 секунд.

В сетке месяца точки событий на прошедших днях отображаются с непрозрачностью 45%. Точки сегодняшнего и будущих дней сохраняют полную непрозрачность. Прошедший день можно открыть, чтобы посмотреть расписание.

Текущее событие с указанным временем выделено слабой акцентной заливкой и обводкой с начала до окончания. События на весь день такого выделения не получают. У остальных карточек обводка приглушена; клавиатурный фокус сохраняет яркую акцентную рамку. Постоянной подписи CalDAV в подвале нет: статус появляется только при обновлении или ошибке.
