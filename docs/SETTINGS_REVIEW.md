# Ревью и полировка настроек

Проверены код и рендеры окна на 720×560, 1100×760 и 1600×1000. Изменения сохраняют независимость Settings Service, страниц, контейнера и окна.

| Наблюдение | Исправление |
|---|---|
| Пункт «Анимации» скрывал новое оформление оболочки | «Внешний вид» перенесён в «Персонализацию»; поиск учитывает описание |
| Группы выглядели как неподвижные подписи | Добавлены индикаторы раскрытия и увеличена область нажатия; группа текущего раздела раскрывается |
| Действия на главной выглядели как обычный текст | У кнопок появилась граница в покое, навигация использует отдельный плоский вариант |
| Недоступные контролы выглядели активными | Добавлены различимые отключённые состояния; пояснения остаются читаемыми |
| Плотные подписи ухудшали чтение длинных страниц | Межстрочный интервал основного текста 1,4; заголовки Literata 1,1; улучшена высота многострочных кнопок |
| Выбранный материал различался только радиокнопкой | Выбранная карточка сохраняет акцентную рамку |
| Компактное окно скрывало нижние элементы оформления | Постоянно видимый индикатор прокрутки при переполнении; фокус прокручивает страницу до активного элемента |

Визуальное направление: графитовая основа, Literata и Inter, сдержанная лавандовая акцентная линия и тонкие разделители. Дополнительные иллюстрации и декоративная анимация не добавлялись.

Визуальный smoke расширен с первых пяти страниц на все 24 существующих раздела, каждый на трёх размерах. Проверены навигация, сохранение, отсутствие циклических сигналов, компактная страница оформления и реальная работа переключателя Solid / Frosted Glass.

Нативное размытие проверено отдельно через Wayland-протокол. Закрытие, повторное открытие, перенос между мониторами, изменение размеров и максимизация тестового окна проверены в Niri.

Не проверены реальные действия над Bluetooth, PipeWire и NetworkManager: в offscreen-проверке эти службы недоступны. Их отсутствие использовано для проверки отключённых состояний. Ежедневная пользовательская сессия не завершалась, глобальные правила Niri не менялись.
