# Nayori

Nayori — личная оболочка рабочего стола для Linux. Она стоит поверх композитора Niri и пишется на Quickshell и QML.

Целевая машина: CachyOS, Wayland, Niri, Quickshell. Сейчас каждый день работает Noctalia. Nayori собирается рядом, в отдельном процессе и со своим путём конфигурации.

Nayori — самостоятельный проект, со своим кодом и своим видом. Крупные куски QML из других оболочек сюда не переносятся. Маленький приём из открытого кода допустим только при ясной лицензии и только если короткая своя реализация хуже. Такое решение каждый раз записано в аудите.

Визуальная рамка, ещё без макета: Anime Editorial и ретро-японская графика. Палитра, шрифты и иллюстрации придут вместе с референсами. В архитектуре есть место для собственного персонажа Nayori. Внешность персонажа в этих документах не задаётся.

## Технологии

- CachyOS
- Wayland, Niri
- Quickshell, Qt Quick, QML

## Изоляция

Nayori разрабатывается и проверяется отдельно от живой сессии. Конфигурация Niri, Noctalia, greetd, автозапуск и системные службы из этого репозитория не меняются. Дальнейшие запуски, которые меняют сессию, описаны в дорожной карте и ждут отдельного согласия.

**Подтверждено.** Сессию поднимает Noctalia: в `~/.config/niri/cfg/autostart.kdl` стоит `spawn-at-startup "noctalia"`.

**Подтверждено.** Пробный экземпляр запущен через `qs -p /home/katamy/Projects/nayori`. Noctalia при этом остаётся в сессии.

**Предположение.** Явный путь не подменяет `spawn-at-startup "noctalia"`. Так устроена справка `qs`.

**Рекомендация.** Пробный экземпляр запускать и останавливать только с явным `--path`.
