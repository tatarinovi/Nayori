# Naomi — спутница Nayori

Два облика переключаются в Настройки → Приложения → Naomi → «Текущий» / «Pixel art». Выбор `companionStyle` сохраняется в `settings.json`; по умолчанию остаётся текущая иллюстрация.

Текущая анимированная иллюстрация (вариант C): `surfaces/companion/NaomiIllustration.qml`. Её показывают окно рабочего стола `CompanionWindow.qml` и предпросмотр на странице «Naomi» в настройках. Pixel art использует утверждённый Hoodie №03 с уточнёнными носом и улыбкой: `NaomiPixelIllustration.qml` рисует индексированные данные `NaomiPixelArt.js` через Canvas без загрузки изображений. Его область — 280 × 400, исходная сетка — 140 × 200. Одежда, глаза, бант и отделка следуют цветам обоев; кожа и волосы сохраняют исходные цвета. Пиксельный idle работает на 8 Гц: дыхание, моргание, отдельное движение хвоста, прядей и ленты. При выключенных анимациях возвращается нейтральная поза. Реплики и настройки реакции общие для обоих обликов; переключение не пересоздаёт контроллер.

Сборка Pixel art: `python3 scripts/naomi-build-pixel.py`. Проверка точного совпадения нейтральной позы с утверждённым рисунком, сохранения носа и рта, неподвижности ног и смены палитры: `node tests/naomi-pixel.cjs`. Проверка переключения облика и отрисовки: `tests/smoke/NaomiPixelSmoke.qml`.

## Показ на рабочем столе

Настройки → Приложения → Naomi.

- «Показывать Naomi на рабочем столе» (`companionEnabled`, по умолчанию выключено): окно справа снизу на основном мониторе (первый экран Quickshell), размер 280 × 534 для текущей иллюстрации и 280 × 400 для Pixel art с поправкой на маленький экран. При выключении поверхность выгружается.
- «Только на рабочем столе» (`companionDesktopOnly`, по умолчанию выключено): включено — слой `Bottom`, Naomi видна над обоями и скрыта за окнами; выключено — слой `Top`, Naomi поверх окон приложений, но под лаунчером, меню Пуск и панелью. Переключение действует сразу, без перезапуска.
- Оба параметра хранятся в общем `settings.json`.
- «Реагировать на курсор» (`companionReactToPointer`, по умолчанию включено): окно принимает ввод только в небольшом овале над головой (около 107 × 116 px), остальное — тело, облако и место над головой — прозрачно для кликов. Клики по самому овалу к окнам под ним не проходят. Выключено — `mask: Region {}`, весь ввод проходит сквозь окно, поглаживание и реплики на него отключены. `keyboardFocus: None` в обоих случаях.
- «Комментировать системные события» (`companionSystemLines`, по умолчанию включено): реплики в ответ на нагрузку CPU, бездействие, терминалы и игры, число окон, батарею, ночь, обновление и потерю сети; выключено — источники не опрашиваются, остальные реплики работают. Список и правила — `docs/NAOMI.md`.
- Окно выше иллюстрации на 128 px: над головой показывается облако с репликой. Подробности — `docs/NAOMI.md`.
- На рабочем столе голова слегка поворачивается к курсору только над овалом головы. В предпросмотре настроек она следует за курсором по всей карточке.

## Слои и прозрачный фон

- Слои: `assets/naomi/layers/*.png` и манифест `surfaces/companion/NaomiLayers.js`. Создаются `python3 scripts/naomi-make-layers.py` из `assets/naomi/candidates/naomi-variant-c-graphic.jpg`; вручную не править.
- Фон прозрачный: альфа — мягкая маска силуэта (размытие 0,7 пикселя). Полости (туфли, пряди) залиты тёмным тоном волос и одежды. Цвет пограничных пикселей берётся из внутренней области, поэтому на светлых обоях нет тёмного ободка.
- Шарф, повязка и заколка — яркостные маски с `MultiEffect.colorization` цветом `secondary` из палитры обоев. Кожа, волосы, одежда и глаза фиксированы.
- Движение: дыхание, покачивание волос и шарфа, моргание, редкое движение ушек. При `tokens.motion.off` или выключенных анимациях — статичный кадр.
- Эмоция поглаживания: слои `eye_happy_left/right` (глаза-дуги), `mouth_smile` (кожа поверх закрытого рта и улыбка), `blush_left/right` (белая маска румянца, красится `secondary`). Их рисует тот же `scripts/naomi-make-layers.py` векторно с восьмикратным сглаживанием, они показываются только при поглаживании.
- Источник для генератора — `assets/naomi/candidates/naomi-variant-c-graphic.jpg` (каталога `assets/companion/` в репозитории нет). Запуск детерминирован: прежние 18 слоёв воспроизводятся побайтно. Необязательный аргумент — путь для контрольной сборки в покое: `python3 scripts/naomi-make-layers.py /tmp/composite.png`.
- Кадры: `assets/naomi/previews/` (покой, моргание, качание, облако `naomi-bubble.png`, поза поглаживания `naomi-petted.png`). Тест слоёв: `python3 tests/naomi-layers.py`.
- Кадры-кандидаты №1–5 лежат в `assets/naomi/candidates/` и не используются; `naomi-variant-c-graphic.jpg` оттуда — источник слоёв.
