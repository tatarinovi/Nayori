# Naomi — чиби

Отдельный облик «Чиби» выбирается в «Настройки → Naomi → Внешний вид». Рисунок выводится на холсте 200 × 200 без сглаживания, с прозрачным фоном. Исходные позы созданы по образу Naomi в хаори и уменьшены до 200 × 200; они не являются совместимыми кадрами одной анимации.

- `idle.png` — основной кадр;
- `blink.png` — нарисованные на пиксельной сетке закрытые глаза для моргания и поглаживания;
- `thoughtful.png`, `wave.png`, `hand-on-chest.png` — дополнительные исходные позы, пока не используются в автоматической анимации: их нужно отдельно совместить с idle и подготовить промежуточные кадры.

В спокойном состоянии Naomi моргает и сдвигается на один пиксель; при поглаживании закрывает глаза. Отключение анимаций останавливает таймеры. Положение и поведение облака, системные реплики и взаимодействие остаются общими для обликов.
