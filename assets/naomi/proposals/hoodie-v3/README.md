# Naomi — эскиз Hoodie №03, статичный предпросмотр

Этот статичный рисунок утверждён и используется как исходник облика Pixel art. `Preview.qml` остаётся отдельным стендом для проверки исходного рисунка.

- Источник: `source-sheet.png`, третий персонаж из утверждённого листа ImageGen.
- `scripts/naomi-proposal-v3.py` отделяет фон и переводит исходные пиксели в сетку 140 × 200 с индексированной палитрой. Лицо, одежда и пропорции берутся из исходника. После уменьшения применяются точечные правки носа и улыбки из `face-details.json`: 9 пикселей сетки, без изменения глаз, формы лица и силуэта. Изменения относительно исходника: удаление фона, уменьшение ближайшим соседом и сокращение палитры до 63 непрозрачных цветов.
- `Sprite.js` и `sprite.json` содержат одинаковые палитру и горизонтальные полосы пикселей. PNG исходника не нужен во время отрисовки.
- `Preview.qml` рисует эти данные прямоугольниками Canvas в масштабе 2×, без сглаживания, и сохраняет кадр 280 × 400. `preview.png` и `preview-face-v2.png` — результат настоящей QML-отрисовки с уточнёнными носом и ртом, а не новая сгенерированная иллюстрация.

`python3 scripts/naomi-build-pixel.py` строит из `sprite.json` рабочий `surfaces/companion/NaomiPixelArt.js`: раздельные индексы палитры, движения хвоста, прядей, банта и тела, моргание. В нейтральной позе исходные пиксели совпадают полностью; во время работы меняются только назначенные цвета и поза. Рабочий компонент — `NaomiPixelIllustration.qml`, настройка — Приложения → Naomi → Pixel art.

Повторная сборка данных:

```sh
python3 scripts/naomi-proposal-v3.py
```

Предпросмотр:

```sh
qs -p assets/naomi/proposals/hoodie-v3/Preview.qml
```

Путь снимка задаёт `NAYORI_PROPOSAL_OUTPUT`; по умолчанию `/tmp/naomi-v3-qml.png`.
