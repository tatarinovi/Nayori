# Nayori Zen Clock

A digit-and-colon subset of **Zen Old Mincho Regular**, created by Yoshimichi
Ohira and the Zen Old Mincho Project Authors. The subset is renamed to avoid
conflicts with installed fonts and contains only the glyphs used by the desktop
clock. Digits were adjusted to equal advance widths to keep the time stable
as it changes. The original font and sources are available at:

https://github.com/google/fonts/tree/main/ofl/zenoldmincho
https://github.com/googlefonts/zen-oldmincho
